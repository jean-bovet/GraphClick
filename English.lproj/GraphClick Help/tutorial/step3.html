Add data points

To add data points:

  • if necessary, select the corresponding tool (Tool > Add Point, ⌘2)
  • click on the data points on the graph

The data points are added to the current data set, after the last point selected in the list.

Automatic curve detection

GraphClick can automatically digitize lines. To digitize a line:

  • select the corresponding tool (Tool > Add Points on Horizontal Curve, ⌘3 or Tool > Add Points on Curve, ⌘4)
  • click on the line you want to digitize
  • adjust the tolerance and spacing values to obtain the desired result
