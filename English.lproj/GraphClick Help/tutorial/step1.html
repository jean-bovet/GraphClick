Insert the image of your graph

To insert the image of your graph, you may either:

  • paste it into the document
  • drag the file containing the image and drop it into the document
  • or select File > Open (⌘O) and choose the desired file

Most image formats, as well as movie formats are recognized.

Note

If your screen is cluttered with windows so that it is hard for you to drag a file and drop it onto a document, you may want to use, while dragging a file, ⌘Tab or ⇧⌘Tab to switch between applications, or use Exposé (e.g. F11 to reveal the desktop). You can also drag a file onto the GraphClick icon in the Dock.
