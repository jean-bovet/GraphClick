Export the data

To export the coordinates of the current data set, you may either:

  • copy the coordinate values to the clipboard (Edit > Copy Values, ⇧⌘C)
  • or export the coordinate values to a file (File > Export Values, ⌘E)

Note

In order to select which coordinates or what additional information you want to copy to the clipboard (such as column headers, geometry information, etc.), choose Edit > Copy Values with Settings (⌥⇧⌘C).
