Export

To export the coordinates of the points in data set:

  • select Edit > Copy Values (⇧⌘C) to copy the values to the clipboard, or
  • select File > Export Values (⌘E) to export the values to a file

You can select which coordinates you want to export, as well as if you want to export stacked values (i.e. coordinate differences) or if you want to include additional information (such as column headers, geometry information, etc.). You can also use Edit > Copy Values with Settings (⌥⇧⌘C) to display the dialog before copying the values to the clipboard.

Exporting multiple data sets

To export several data sets at once, you can select more than one data set from the list shown in the top part of the lateral drawer. If you copy the values to the clipboard, all data are merged together. If you select File > Export Values (⌘E), you can choose between exporting each data set in a separated file, or merging all data into a single file.
