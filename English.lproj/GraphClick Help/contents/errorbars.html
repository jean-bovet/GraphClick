Error bars

To add x- or y-error bars to a point:

  • select Tool > Add Point (⌘2)
  • keep the ⇧ key down and click on a point to select it
  • keep the ⌘ key down and click beside the point to add horizontal or vertical error bars
  • keep both the ⌘ and ⇧ keys down to add symmetric error bars to a point

The values of the errors are displayed in the rightmost columns of the point list (to display the drawer, select Display > Show Data Sets) and can also be modified there. The values of the error bars are automatically included when exporting data.

To remove the error bars of the selected points, select Options > Remove Error Bars. You can also modify the error values for all selected points at once in the Points Inspector .
