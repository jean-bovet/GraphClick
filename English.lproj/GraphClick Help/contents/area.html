To show or hide the Area Info window, select Display > Show/Hide Area Info (⌃⌘I).

Area Info

The list in the area info window shows the perimeters and areas of all data sets that define a surface area. Data sets created with the tools Add Points on Perimeter Area (⌘7) and Add Points on Perimeter Areas (⌘8) are automatically set to define areas. Otherwise, check the item Data set defines surface area from the Appearance Inspector. To display this inspector, select Display > Show/Hide Inspector (⇧⌘I) and select .

Perimeter

Measures the perimeter of the area defined by the data points.

Area

Measures the surface area of the area enclosed by the data points. Note that the area is signed: an area is positive if it is enclosed by a curve running clockwise around it, negative otherwise.

Export the values

Click on the button Copy to copy the selected rows or columns (or all values if nothing is selected) into the clipboard.
