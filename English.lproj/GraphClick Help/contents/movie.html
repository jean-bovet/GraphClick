Inserting a movie

To insert a movie into a document, you may either:

  • drag the file containing the movie and drop it into the document (or onto the GraphClick icon in the Dock)
  • or select File > Open (⌘O) and choose the desired file

Changing the displayed frame

You can choose the frame of the movie which is displayed in the document in the Movie Inspector. To display the inspector, select Display > Show Inspector (⇧⌘I) and click on the Movie icon: .

You can also use the items of the menu Movie (such as ⌘⇠ or ⌘⇢) to navigate within the movie.

In the Movie Inspector, check Display Points in Current Frame Only to hide all points which do not correspond to the selected time frame.

Check Automatically Step Forward After Inserting Point to automatically select the next movie frame after inserting a point or detecting points automatically. This is particularly helpful to quickly digitize for instance the position of a moving object by clicking once on each frame, with the tool Add Point (⌘2). You can also automatically move forward to the next movie frame by Control-click, or move backward to the previous movie frame by Shift-Control-click.

Time origin

By default, the time origin is set to the beginning of the movie. You can change the frame corresponding to t = 0 by selecting Movie > Set Origin. Select Movie > Go to Origin to display the frame corresponding to t = 0.

Recognized movie file formats

GraphClick accepts all movie file formats which are compatible with QuickTime.
