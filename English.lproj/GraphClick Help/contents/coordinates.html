Adjust the coordinates

When a new image is inserted into the document, or when selecting Tool > Adjust Coordinate (⌘0), a dialog appears where the user can choose its preferred way to adjust the coordinates. (To prevent this dialog from appearing on each insertion, uncheck the corresponding option in the GraphClick > Preferences (⌘,) window under General.)

After choosing the desired option, the must select a set of positions (either a point or a side, as indicated on the bottom line of the window), entering after each click the corresponding coordinate(s).

Abscissa & Ordinate

The user selects the four sides of the graph.

Basis

The user selects the origin of the graph followed by the right and top sides of the graph.

2 Corners

The user selects two opposite corners of the graph.

3 Corners

The user selects the origin of the graph, followed by the rightmost point on the x-axis and the topmost point of the y-axis. This option is especially useful if the axes are not perpendicular.

4 Corners

The user selects the origin of the graph, followed by the rightmost point on the x-axis, the topmost point of the y-axis and the right-hand corner. This option is especially useful if the graph is deformed.

Abscissa/Ordinate Only

This option allows the user to modify only one axis.

Origin

Shifts the origin to the selected position.

Scale

The user selects two points on the graph and then enters the length of the line connecting these two points. This option is especially useful when digitizing points on maps (i.e. when distances along the x and y axes are the same).

Position of the coordinate limits

The position of the coordinate limits are indicated by the dotted frame. This coordinate frame can be modified by selecting the corresponding tool (Tool > Modify Coordinate Frame).

With this tool, you can:

  • drag a side of the frame
  • drag a corner of the frame
  • move the whole frame
  • create a new rectangular frame by clicking outside of the current frame

To restore the default rectangular frame, select Options > Reset Coordinate Frame. To adjust the frame so that each pair of sides is parallel, select Options > Adjust Coordinate Frame.

Values of the coordinate limits and scales

The coordinate limits and scales can be modified in the Coordinates Inspector. To display the inspector, select Display > Show Inspector (⇧⌘I) and click on the Coordinates icon: . The different available scales are:

  • Linear
  • Logarithmic (log)
  • Inverse (1/x)

Using pixel coordinates

To use the pixel coordinates, check the corresponding option in the Coordinates Inspector.

Using two ordinate axes

If your graph contains two y-axes, check the option Use Two Ordinate Axes in the Coordinates Inspector. You can then assign each data set to either axis by using the menu which appears above the coordinate limits.
