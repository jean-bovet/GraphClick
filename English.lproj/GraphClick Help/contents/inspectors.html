To show or hide the inspector, click on the corresponding icon in the window toolbar, or select Display > Show/Hide Inspector (⇧⌘I). You can create several inspectors by choosing Display > New Inspector.

Coordinates Inspector

In this inspector, you can modify the coordinate limits and the scale for both abscissa (x) and ordinate (y) axes.

Image Inspector

In this inspector, you can:

  • change the angle, scale and opacity of the image
  • make the background transparent
  • change the width and height of the view, or adjust it to the image

Appearance Inspector

In this inspector, you can:

  • change the color of the selected data set
  • choose to connect the points by lines
  • change the style of the markers
  • indicate if the data set defines an area

Points Inspector

In this inspector, you can modify at once:

  • the coordinates
  • the error bar values

of the selected points.

Deformation Inspector

This inspector shows the deformation points of the axis. You can modify the coordinate of a point by double-clicking on its value.

Learn more about deformations

Movie Inspector

This inspector allows you to choose:

  • the frame of the movie which is displayed in the document
  • the value of each time step used when stepping forward or backward

You can also use the items of the menu Movie (such as ⌘⇠ or ⌘⇢) to navigate within the movie.

Check Display Points in Current Frame Only to hide all points which do not correspond to the selected time frame. Check Automatically Step Forward After Inserting Point to automatically select the next movie frame after inserting a point or detecting points automatically. This is particularly helpful to quickly digitize for instance the position of a moving object by clicking once on each frame, with the tool Add Point (⌘2).
