Inserting an image

To insert the image of your graph, you may either:

  • paste it into the document
  • or drag the file containing the image and drop it into the document (or onto the GraphClick icon in the Dock)
  • or select File > Open (⌘O) and choose the desired file

Note

If your screen is cluttered with windows so that it is hard for you to drag a file and drop it onto a document, you may want to use, while dragging a file, ⌘Tab or ⇧⌘Tab to switch between applications, or use Exposé (e.g. F11 to reveal the desktop).

Modifying the image

In the Image Inspector, you can modify:

  • the scale of the image
  • the rotation angle of the image
  • the opacity of the image

To display the inspector, select Display > Show Inspector (⇧⌘I) and click on the Image icon: .

To adjust the size of the document to the image, click on the button Adjust, or enter the desired with and height of the view.

Image Filters

Select Options > Modify Image to modify the image by applying any of the following filters:

  • Threshold
  • Color controls (saturation, brightness or contrast)
  • Detection of edges
  • Blur
  • Sharpen
  • Exposure adjustment
  • Noise reduction

Note: This feature is only available with Mac OS X 10.4 or later.

Recognized image file formats

GraphClick recognizes most image file formats, such as:

  • GIF
  • JPG
  • PNG
  • TIFF
  • PSD (Photoshop)
  • PDF
  • BMP
  • PICT
  • PAINT
  • etc.
