Mask

The mask defines the area where the automatic detection takes place. It is useful to digitize dotted or dashed lines:

  • select Mask > Brush (⌘B) and define a mask my clicking and dragging the brush cursor over the different segments of the curve
  • select any tool and click on the element you want to digitize (curve, bars, symbols, etc.)

You can also add a rectangular region to the mask by selecting Mask > Rectangle (⌘B). To erase some part of the mask, selection Mask > Eraser. To clear the whole mask at once, select Mask > Clear Mask.

The brush size can be changed from the window toolbar or from the GraphClick > Preferences (⌘,) window (under Detection). Select Display > Customize Toolbar to add or remove the item from the toolbar.

Detecting jittery curves

If the curve you try to digitize is too jittery, the curve detection algorithms may fail to "follow" the line, even if you try to change the tolerance value. In this case, you should use a mask together with the horizontal curve detection algorithm (⌘3), which then detects one point per abscissa, instead of following the curve.
