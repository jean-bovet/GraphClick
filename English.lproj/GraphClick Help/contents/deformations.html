Non-cartesian deformations

If the axis on the image of the graph are not aligned to the horizontal and vertical directions, try to:

  • rotate the image in the Image Inspector

You can also deform the coordinate frame by chosing Tool > Modify Coordinate Frame and moving a corner:

  • with the ⇧ key down to deform the frame horizontally
  • with the ⌃ (control) key down to deform the frame vertically
  • with the ⌘ key down to move each corner independently

Handling more deformations

This section describes how to adjust the coordinate frame when the ordinate (y) axis is deformed. This option is useful if:

  • the ordinate axis is curved and/or
  • the scale of the ordinate is irregular

Select Tool > Deform Axis and click on a point of the deformed ordinate axis in the image. Repeat this step a few times until the side of the coordinate frame matches the image of the deformed axis.

Note that any number of actions in GraphClick can be undone or redone by selecting Edit > Undo (⌘Z) or Redo (⇧⌘Z), respectively.

The list Deformation Points in the Deformation Inspector indicates the y-coordinate of each deformation point. Click on a value in the list to select the corresponding point. The selected deformations points are indicated by dots on the coordinate frame. If necessary, change the value of these coordinates (by double-clicking on the list items) to match the positions on the graph.
